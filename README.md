# 🌊 Clean Coast AI (클린코스트 AI)
> **제주시 주요 5개 해수욕장 해안쓰레기 발생량 예측 및 적정 청소 인력 배치 시스템**

🔗 **웹 서비스 바로가기:** [Clean Coast AI 실행하기](https://meineroluv.github.io/clean-coast-ai/)

---

## 1. 기획 배경 및 목적
- **현장 문제:** 일부 유명 해수욕장에만 청소 인력이 집중되고 인접 해변은 관리 사각지대로 남는 불균형이 발생하고 있습니다.
- **기대 효과:** 객관적인 데이터를 바탕으로 해변별 쓰레기 발생량을 예측하여 **지역 간 환경 형평성**을 높이고, 적정 인원을 배치해 **현장 근로자의 과로와 안전사고를 예방**합니다.

## 2. 핵심 기능
1. **해수욕장 및 환경 데이터 입력:** 제주시 5개 해수욕장 선택 시 백사장 실측면적 자동 반영, 예상 이용객 수 및 평균 풍속 입력
2. **예상 쓰레기 수거량 예측:** 다중 선형 회귀모델($R^2 = 0.92$)을 적용한 예상 수거량(kg) 실시간 산출
3. **핵심 파생 속성 자동 계산:**
   - **방문객 밀도(명/㎡):** 단위 면적당 관광객 혼잡도 산출
   - **기상 가중치:** 평균 풍속에 따른 3단계 유입 위험 지수(1.0 / 1.2 / 1.4) 부여
   - **추천 배치인원(명):** 작업자 1인당 표준 처리 한계(300kg) 기준 최소 필요 인원 올림 산출
4. **청소 우선순위 대시보드:** 5개 해수욕장의 예측 발생량을 비교해 청소 시급성 순위(1~5순위) 제공

## 3. 분석 데이터 및 출처
- **분석 대상:** 제주시 주요 5개 해수욕장 (곽지, 금능, 김녕, 삼양, 이호테우) / 2021~2025년 총 25건
- **데이터 출처:** 공공데이터포털(해수욕장 이용객 현황), 카카오맵(백사장 실측면적), 기상청 기상자료개방포털(AWS 연평균 풍속), 해양환경정보포털(국가 해안쓰레기 모니터링 통계)
